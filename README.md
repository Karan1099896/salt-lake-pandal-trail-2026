# Salt Lake Pandal Trail

Build a complete, polished, mobile-first website called “Salt Lake Puja Trail 2026” for a maximalist Durga Puja pandal-hopping checklist in Salt Lake, Bidhannagar, Kolkata. The user wants the final shortlist of five pandals: EC Block, FD Block, AK Block, BJ Block, and Labony Estate. Include location, area/block address, clickable Google Maps search/directions link for each, and interactive checklist. IMPORTANT: Do not invent precise street addresses, exact 2026 themes, awards, opening hours, or facts that are not verified. Present addresses as block/area-level locations and label them “Block-level location; confirm pin locally.” For EC Block, show “EC Block, Salt Lake, Bidhannagar, Kolkata, West Bengal” and mention the 2026 Mahabharat theme only as reported/unverified if included; safer to label theme “Confirm on arrival.” FD Block: “FD Block, Sector III, Bidhannagar, Kolkata, West Bengal.” AK Block: “AK Block, Salt Lake, Bidhannagar, Kolkata, West Bengal.” BJ Block: “BJ Block, Salt Lake, Bidhannagar, Kolkata, West Bengal.” Labony Estate: “Labony Estate, Salt Lake, Bidhannagar, Kolkata, West Bengal.” Each card should have buttons “Open in Google Maps” and “Mark visited”, plus an individually togglable checklist state persisted in localStorage. Add global progress bar and visited count (0/5), filters for All / To visit / Visited, a reset checklist confirmation, a “copy/share itinerary” button, and a route plan grouping Sector I (EC, Labony Estate) then Sector II (AK, BJ) and Sector III (FD), clearly label this as a suggested grouping and not a guaranteed shortest route. Include a useful checklist: phone charged, power bank, water, comfortable shoes, cash/UPI, check crowd/traffic, check local access, confirm pandal location. Build beautiful maximalist visual design: festival poster energy, rich vermilion red, marigold orange, hot pink, cobalt blue, emerald, gold accents, layered decorative borders, oversized editorial typography, Bengali-inspired ornamental patterns (avoid faux text), illustrated dhaak/lotus/Alpona motifs, paper textures, stickers, ribbons, marquee/ticker, asymmetrical card layouts, expressive but legible. High-quality animations: entrance reveals, hover spring, progress animation, subtle parallax or floating decorative shapes, interactive checklist feedback; respect prefers-reduced-motion and keep mobile performance good. Create responsive desktop/tablet/mobile layouts, accessible contrast, semantic HTML, keyboard-accessible controls. Include hero section with “PANDAL HOPPING, MAXIMALIST MODE”, date context “Durga Puja 2026 • Salt Lake, Kolkata” and note that puja dates/events and access should be confirmed locally. Sections: Hero, five pandal cards, route plan, master checklist, footer. Use working UI, no dead buttons. Use a tasteful map pin illustration; do not embed fake maps or claim live location. Deliver the complete functioning website, not just a mockup.
